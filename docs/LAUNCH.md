# Launch checklist

## What already works (verified)
* Complete game, economy, menus, audio, daily systems — tested in headless Chromium (full flow, no errors).
* **Test ads** wired end-to-end: web shows a fake ad overlay; the Android/iOS build uses `@capacitor-community/admob`
  with Google's official TEST unit ids (safe to click). Rewarded reward is granted only on the reward event.
* UMP consent form (EU/UK) + iOS ATT prompt are requested at startup on device.
* `scripts/android-setup.js` patches the generated Android project (AdMob app id, permissions, portrait lock, optional signing) — tested locally.
* GitHub Actions: **Android build** → debug APK artifact on every push; optional signed **release AAB** (Run workflow → release).

## When you have your real ids  (only these steps!)
1. **AdMob**: edit `www/js/config.js` — paste app ids + rewarded/interstitial unit ids (Android & iOS), set `testing:false`.
   For CI release builds also add repo secret `ADMOB_ANDROID_APP_ID`.
2. **Identity**: `capacitor.config.json` → `appId` (e.g. `com.yourstudio.orbfall`) and `appName`.
3. **Privacy policy / support**: `privacyUrl`, `supportEmail`, `storeUrl` in `config.js`.
4. **In-app purchases**: add `cordova-plugin-purchase`, create products in Play Console with ids
   `starter`, `noads`, `gems_s`, `gems_m`, `gems_l`, then in the store's *approved* callback call `OF.iap.grant(id)`
   (and implement `OF.iap.restore`). Until then purchases are simulated in-app (confirm dialog).
5. **Signing for Play Store**: create a keystore (keep it safe, never commit), then add repo secrets
   `KEYSTORE_BASE64` (`base64 -w0 release.keystore`), `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`;
   Actions → "Android build" → Run workflow → tick *release* → download the `.aab` and upload to Play Console.
6. Play Console: Data safety form (ads + purchases + analytics), content rating, store listing/screenshots.

## Local build
```bash
npm install
npx cap add android && npx capacitor-assets generate --android && node scripts/android-setup.js
npx cap sync android && cd android && ./gradlew assembleDebug
```
Icons/splash are generated by `node tools/make-icons.js` into `resources/` (replace with your own art any time).
